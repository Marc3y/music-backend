# music-backend

Dieses Projekt ist die eine Hälfte des music-Projekts. Die Inspiration liegt hierbei bei dem Projekt untitled. Auf der Seite kann man Songs, Beats und Projekte hochladen und in verschiedenen Playlists kategorisieren, sowie bestimmte Songs, Projekte oder auch Playlists mit anderen Personen teilen.
Ebenfalls ist es möglich, Personen als Collaborator bestimmter Playlists hinzuzufügen.
